# Project brief

## Продукт
Telegram-система для автоматического сбора заказов из чатов городов и выгрузки результата в Excel.

## Основной сценарий
1) Админ создает раздачу для чата.
2) Админ вручную заносит каталог товаров (позиции, фасовка, единицы, кратности, синонимы).
3) Админ запускает сбор.
4) Пользователи пишут заказы в чат.
5) Система распознает заказ:
   - имя (из сообщения или профиля, иначе просит указать)
   - номер (последние 4 цифры телефона, обязателен)
   - пункт выдачи (обязателен)
   - позиции (хотя бы 1, по каталогу)
6) Система отвечает пользователю в чат: принято/частично/не принято, с причинами и подсказками.
7) Админ делает экспорт Excel по раздаче.

## Ограничения
- Историю до добавления системы не читаем.
- В одном чате одновременно одна активная раздача.
- Каталог внутри раздачи фиксирован, новые товары в ходе раздачи не добавляются.
- Стопы ставит только админ, действуют с момента установки.
- Редактирование сообщений учитываем: используем итоговую версию без дублей.

## Нагрузка
- До 100 000 сообщений-заказов на чат за 2 недели.
- Обычных сообщений может быть очень много, требуется эффективная фильтрация.
