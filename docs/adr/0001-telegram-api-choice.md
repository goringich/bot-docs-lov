# ADR 0001 - Telegram API choice

## Status
accepted

## Context
Нужно получать сообщения из чатов, отвечать пользователям, обрабатывать edited_message. Историю до добавления системы не читаем. На MVP админка - через личку с ботом командами. Privacy mode можно выключить.

## Decision
- Используем Telegram Bot API.
- Получение апдейтов: webhook.
- Privacy mode: выключен (бот видит все сообщения в группе).
- Админские операции: команды в личке с ботом (MVP).
- Обработка апдейтов: gateway сохраняет raw update, тяжелая обработка в worker.

## Consequences
- Входной endpoint должен отвечать быстро, чтобы избежать ретраев Telegram и дублей.
- Потребуется строгая идемпотентность по update_id и корректная модель edited_message.
- Для масштабирования в будущем worker можно размножить горизонтально.
