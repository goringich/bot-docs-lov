## Что не реализовано

### 1. **Редактирование заказов в UI**
Сейчас UI только для просмотра (read-only).

**Требуется:**
- Кнопка "Edit Order" в модальном окне
- Изменение количества в строках
- Добавление/удаление позиций
- API endpoints: `PATCH /orders/{id}`, `POST /orders/{id}/lines`

### 2. **Управление каталогом в UI**
Каталог редактируется только через админ-команды в Telegram.

**Требуется:**
- Страница `CatalogManagementPage`
- CRUD для товаров (добавить/редактировать/удалить)
- Импорт каталога из Excel

### 3. **Просмотр Excel в UI**
Нельзя посмотреть сгенерированный Excel прямо в браузере.

**Требуется:**
- Таблица `export_reports` для хранения истории
- Интеграция SheetJS для preview
- Endpoint `GET /reports` для списка файлов

### 4. **Real-time уведомления**
Админ не видит новые заказы до обновления страницы.

**Требуется:**
- WebSocket или Server-Sent Events (SSE)
- Toast-уведомления в UI
- Redis Pub/Sub для multi-worker setup

### 5. **Автоматические бэкапы**
Нет встроенной системы резервного копирования.

**Требуется:**
- Cron-скрипт для `mysqldump`
- Хранение на внешнем storage (S3/MinIO)
- UI для восстановления из backup

### 6. **Тесты и CI/CD**
Нет автоматических тестов и пайплайнов.

**Требуется:**
- Unit tests (pytest)
- E2E tests (Playwright)
- GitHub Actions для lint/test/build
