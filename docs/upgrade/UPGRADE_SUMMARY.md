# 🎉 v2.0 Production Upgrade — Summary

## Что сделано

### 1️⃣ База данных (Backend)
Добавлены 2 новые таблицы в `backend/app/models.py`:
- **`bot_settings`** — ключ-значение для настроек бота
- **`pickup_places`** — справочник точек выдачи с активностью

Создана миграция: `c9f8a1234567_add_bot_settings_and_pickup_places.py`
- Автоматически заполняет дефолтные настройки и 3 точки выдачи

### 2️⃣ Улучшенный UX бота (Backend)
Файлы: `backend/app/presenter/order_presenter.py`, `backend/app/domain/order_domain.py`, `backend/app/worker.py`

**Изменения:**
- Минималистичные кнопки: 4 основных → 2 после успешного заказа
- Сообщения с emoji (✅ ⚠️ ❌ 📋)
- Компактные ответы вместо "стен текста"
- Улучшенная функция `looks_like_order()`:
  - Игнорирует рецепты (по ключевым словам: "рецепт", "приготовить", "ингредиенты")
  - Фильтрует медиа-ссылки (t.me, youtube.com)
  - Отсекает длинные тексты (>500 символов)

### 3️⃣ Admin API (Admin Service)
Файл: `admin_service/app/main.py`

**Новые эндпоинты:**
- `GET /settings` — получить все настройки
- `POST /settings` — обновить настройки
- `GET /pickup-places` — список точек выдачи
- `POST /pickup-places` — создать точку
- `PATCH /pickup-places/{id}` — изменить точку
- `DELETE /pickup-places/{id}` — удалить точку

### 4️⃣ Admin Web UI (Frontend)
Файлы: `admin-web/src/App.tsx`, `admin-web/src/api/client.ts`, `admin-web/src/pages/*`

**Новые фичи:**
- **Тёмная тема** с переключателем в header (сохраняется в localStorage)
- **SettingsPage** — полноценная страница настроек:
  - Режим ответов: DM / в чате / оба
  - Кастомизация текстов (приветствие, успех, ошибка)
  - Управление точками выдачи (добавить/редактировать/удалить)
  - Настройки уведомлений
- **CSV экспорт** на OrdersPage (кнопка "Экспорт CSV")
- **Графики** на AnalyticsPage (bar-charts с анимацией)

## ⚠️ Важные замечания

1. **Миграция обязательна** — без неё новые API эндпоинты не будут работать
2. **bcrypt версия зафиксирована** — требуется 3.2.2 (уже в requirements.txt)
3. **Настройки живут в БД** — больше не зависим от `.env` для текстов и точек
4. **Тёмная тема** — сохраняется автоматически, но требует JavaScript в браузере

## 🐛 Если что-то не работает

### Проблема: Настройки не сохраняются
**Решение:** Проверь миграцию:
```bash
docker exec tg_orders_api bash -c "cd /app/backend && alembic current"
# Должна быть: c9f8a1234567 (head)
```

### Проблема: Тёмная тема не переключается
**Решение:** Очисти кеш браузера (Ctrl+Shift+R) или проверь localStorage в DevTools

### Проблема: Бот отвечает старыми сообщениями
**Решение:** Перезапусти worker:
```bash
docker restart tg_orders_worker
```
