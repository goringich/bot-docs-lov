# Glossary

- Чат - Telegram-группа, где пишут заказы.
- Раздача - период сбора заказов в чате.
- Каталог - список товаров, введенный админом перед началом раздачи.
- Товар - позиция каталога с правилами распознавания.
- Стоп - состояние товара, при котором новые заказы по нему не принимаются.
- Сообщение - входное сообщение Telegram.
- Сообщение-заказ - сообщение, распознанное системой как заказ.
- Пункт выдачи - локация выдачи, обязательна в заказе.
- Заказ клиента - агрегированное состояние по пользователю внутри раздачи.
